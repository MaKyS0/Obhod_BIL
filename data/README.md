# Данные

| Файл | Назначение |
|---|---|
| `demo.json` | **DEMO**: вымышленные ученики и персонал для проверки сайта. Загружается кнопкой «Загрузить DEMO-данные» (Настройки или пустая Главная); все записи получают пометку `DEMO` и удаляются кнопкой «Удалить DEMO-данные». |
| `example-students.csv` | Пример CSV со списком учеников (шаблон колонок). |
| `example-staff.csv` | Пример CSV со списком классных руководителей и воспитателей. |
| `example-import.json` | Пример простого JSON-файла для импорта. |

Реальные данные в репозиторий не кладите — загружайте их через раздел «Импорт и экспорт» (они сохраняются только в вашем браузере).
