# Google Apps Script для «Учёта лицея»

| Файл | Назначение |
|---|---|
| `Code.gs` | Код скрипта (вставляется в Apps Script таблицы). |
| `appsscript.json` | Манифест (необязателен). |
| `index.html` | **Пошаговая инструкция** (откроется на сайте: Настройки → Google Таблицы → «Пошаговая инструкция»). |

Кратко:

1. Создайте Google Таблицу → **Расширения → Apps Script**.
2. Вставьте содержимое `Code.gs`, сохраните.
3. Запустите функцию `setup()` (разрешите доступ), скопируйте токен.
4. **Развернуть → Новое развёртывание → Веб-приложение**: «Выполнять как» — *Я*, «Доступ» — *Все*. Скопируйте URL (`…/exec`).
5. На сайте: **Настройки → Google Таблицы** — вставьте URL и токен, «Сохранить».
6. «Проверить соединение» → «Выгрузить в Google Таблицы».

Подробности, решение проблем и безопасность — в `index.html`.
